# Jyotish Query
## Custom Locations

If comparing Jyotish query charts with applications you are familiar with you may need to compare the Longitude and Latitude lookups to make sure they match. 

If you can't find the location you want in OpenStreetMap (which is what Jyotish Query uses) it's possible to create your own location record.

- in Name/City field enter a custom name - don't bother clicking Lookup.
- Enter the longitude and latitude. You can use any of these three formats
  - 120W22  40N20
  - -120:22 40:20
  - -120.3666 40.3333
- Enter nominal UTC timezone - this can be overriden in the New Chart dialog for timezones and Daylight Saving values that require adjustment if they have changed since the birth time of the native.
