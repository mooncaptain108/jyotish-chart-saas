# Jyotish Query
### Transits Control
1. When a chart is created or an existing chart is selected the transit data is set automatically to the current time/date and the location of the loaded chart. 
2. For example when an existing chart is selected the time/date and location are set and, without selecting a transit view, a transit chart is available from the Divisional chart drop down list. Select the transit view to see the planetary speeds on the chart. The transit analysis is on the Analysis popover's Transits and Chart & Transits tabs, from any view.
3. Whenever a transit is on screen a control bar appears directly below the chart, in two lines (Settings &gt; **Transit Control Position** can move it above the chart instead, or to the bottom of the Dasha Periods panel, where the controls stack one per line):
   - **Now** &mdash; jump the transit back to the current date and time.
   - **Time**, then **Date** &mdash; type or pick the transit moment directly.
   - **Slider** &mdash; drag right to move the transit forward, left to move it back. The slider is centred on whatever moment is currently set, and springs back to the centre when you let go, so you can drag it again in the same direction as many times as you like.
   - **&#9664; &#9654;** &mdash; move the transit back or forward by exactly one unit per tap. Easier than the slider on a small touch screen.
   - **Second / Minute / Hour / Day / Month / Year** &mdash; the unit the slider and the arrows move by (Day is the default).
   - Second line: the **location** list, so the transit can be moved to another saved place without leaving the chart.
4. The UTC offset (including daylight saving) for the transit location and date is worked out automatically from the location's time zone.
