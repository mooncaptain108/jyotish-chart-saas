# Jyotish Query
### Transits Control
1. When a chart is created or an existing chart is selected the transit data is set automatically to the current time/date and the location of the loaded chart. 
2. For example when an existing chart is selected the time/date and location are set and, without selecting a transit view, a transit chart is available from the Divisional chart drop down list. Select the transit view to see the planetary speeds on the chart and to be able to select the strength analysis for the transits. 
3. 
   - The Transits Control dialog loads automatically when View/Transits or View/Chart & Transits is chosen from the menu.  
   - However, this isn't required, and there is an option on the dialog to turn off the auto loading behavior. 
   - It also can be opened directly with the View/Transits Control choice.
4. You only need to load the Transits Control if you want to change the time/date or location of the transit display.
