# Jyotish Query
## Views

The View menu switches what the main chart wheel is showing, and gives you a couple of related lookup tools.

- **Chart** — the natal chart. This is the default view when a chart is loaded.
- **Transits** — replaces the natal planet positions on the wheel with the transit planets, using the same ascendant/houses as the natal chart. Planet speeds are shown, and the strength/affliction Analysis can be run against the transit positions.
- **Chart & Transits** — shows the natal chart with the transit planets overlaid, so you can see conjunctions/aspects between the two at a glance. Analysis here compares natal and transit placements directly rather than scoring transit strength on its own.
- **Transits Control** — opens the dialog where you set the transit location, date and time. See the separate Transit Control help topic for details. Selecting Transits or Chart & Transits above does **not** open this dialog by itself — the transit date/time/location just carries over from whatever was last set (or defaults to now/the chart's own location the first time). Open Transits Control explicitly whenever you need to change them.
- **Ephemeris Report** — a standalone planet-position table for a location and date range, independent of whatever chart is currently loaded. Useful for scanning planetary positions/speeds over a span of days without stepping through them one at a time.

Once a Transits or Chart & Transits view is on screen (or the Divisional panel is set to Transit), a control bar appears directly below the chart (or above it, or under Dasha Periods &mdash; see Settings &gt; Transit Control Position): **Now**, the transit **time** and **date**, a **slider** that moves the transit forward or back in **second / minute / hour / day / month / year** steps, and underneath it the transit **location** list. That is enough to move the transit around without reopening Transits Control, and it stays reachable on a phone or tablet where the toolbar does not.
